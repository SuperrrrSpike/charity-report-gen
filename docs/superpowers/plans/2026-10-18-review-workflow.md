# 公益报告人工复核工作流实施计划

## 完成条件

- 离线 Mock 工作流可从原始素材运行到三类报告。
- 未通过数字证据检查或未获人工批准时不能渲染。
- 工作区保存状态和只追加审计记录，不保存密钥。
- 单元测试与 CI 端到端演示通过。

## 步骤

1. 为数字证据、状态转移和审计日志编写失败测试。
2. 新增 `scripts/workflow.py`，复用现有提取和渲染函数。
3. 增加与 Mock 案例严格对应的示例原始素材。
4. 增加 `start`、`review` 和 `status` 命令。
5. 更新 README、忽略规则和 CI 离线冒烟测试。
6. 运行完整测试、端到端工作流、密钥扫描和产物检查。
7. 提交、推送并等待 GitHub Actions 验收。
